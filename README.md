# Nguyen Qui Vinh Quang — Academic Portfolio

Personal academic portfolio built with Jekyll and hosted on GitHub Pages.

## Run locally

1. Install [Ruby+Devkit for Windows](https://rubyinstaller.org/downloads/).
2. Open PowerShell in the project folder and run:

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\run-local.ps1
   ```

   The script installs the project gems on first run and starts the local server.
3. Open <http://localhost:4000>. Press `Ctrl+C` in the terminal to stop the server.

## Update portfolio content

- Edit the profile, role, and contact details in `_config.yml`.
- Edit news, experience, publications, authors, and academic service in `_data/`.
- Reviewer entries are grouped by conference in `_data/academic_service.yml`.
- Replace the CV at `assets/CV.pdf` when you update it.
